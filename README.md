# budget

终端记账 App：**Rich TUI + SQLite**，零 Web 依赖。

```bash
./budget          # 或 python3 tui.py
```

依赖 Python 3.9+ 和 `rich`。数据在 `data/budget.db`，单文件，随时可备份。

## 交互模型

**所有动作都是命令**。屏幕底部常驻命令行，裸字母只进缓冲区，不会触发任何动作。
快捷键一律走 **Ctrl+**（终端收不到 Cmd+，Cmd 被 iTerm/Terminal 自己吃掉，不会传给进程）。

非字母键可以直接裸按。

| 按键 | 作用 |
|---|---|
| `Tab` | 切换页面 |
| `←` `→` | 前后一天（报表页是前后一月） |
| `↑` `↓` | 命令历史 / 浏览页选中行 |
| `Enter` | 执行命令 |
| `Esc` | 清空命令行 / 退出报表 |
| `Backspace` | 删除字符 |
| `Ctrl+H` | 帮助 |
| `Ctrl+Q` | 退出 |
| `Ctrl+R` | 月度报表 |
| `Ctrl+T` | 回到今天 |
| `Ctrl+E` | 改选中记录金额 |
| `Ctrl+G` | 改选中记录标签 |
| `Ctrl+D` | 删除选中记录 |

`Ctrl+E/G/D` 只是替你拼好命令（`edit 12 42` / `tags 12 报销` / `del 12`），和手输完全等价。

## 命令

**记账**

```
35 午饭 #餐饮 @同事            记一笔（默认今天）
昨天 42 打车 #交通             指定日期，也支持 前天 / -3d / 2026-10-01
```

**预算**（周期完全自定义）

```
b 50 每周三 12:00 咖啡 #餐饮
b 1200 每月1号 房租 #生活
b 30 每2天 早餐
b 200 每3周 理发
```

周期写法：`每天` / `每周三` / `每周一,三` / `每2天` / `每3周` / `每月1号` / `每年3月1号`
时间写法：`12:00` / `中午` / `晚上`

**模板与其他**

```
p 咖啡 18 #餐饮 12:00          建行动模板
tag 12 +报销 -待定             增删标签
tags 12 报销,同事              整体设置（留空清空）
edit 12 42                     改金额
note 12 改备注                 改备注
cat 12 交通                    改分类
del 12                         删除记录
```

**导航**

```
day 昨天 | day 2026-10-21      跳到某一天
next / prev                    前后一天
today                          回到今天
report                         月度报表
month 2026-09                  指定报表月份
tab input|overview|browse      切页
back                           退出报表
?                              帮助
q                              退出
```

## 三个页面

**输入** — 只有命令行和一行最近记录，没有别的干扰。

**总览** — 当天的支出、分类分布、预算计划，`Ctrl+R` 进月度报表。

**浏览** — 一次只看一天，选中行后 `Ctrl+E/G/D` 就地改；底部是行动模板。

## 月度报表

对每个预算给出周期、当月触发次数、计划金额、实际金额、进度条。

匹配规则是刻意收紧的：

- 记录显式挂到某预算 → 一定计入
- 否则仅当预算声明了 `#分类` 或 `@标签`，且记录落在触发日，才自动计入
- 两者都没有的预算（如「理发 ¥200」）**只做计划，不吞任何消费**

宁可漏算，不可错算。

## 结构

| 文件 | 职责 |
|---|---|
| `tui.py` | Rich 渲染 + 按键循环，纯展示层 |
| `commands.py` | 命令解释器，所有动作的唯一入口 |
| `actions.py` | 用例层，唯一写数据的地方 |
| `db.py` | SQLite schema 与 CRUD |
| `parser.py` | 记账/预算/模板命令的语法解析 |
| `recurrence.py` | 周期规则引擎 + 月报聚合 |
| `fmt.py` | 共享格式化 |

分层是刻意的：`commands.py` 只碰 `state` 和 `actions`，`tui.py` 只渲染。
想加 CLI、HTTP、Raycast 脚本，调 `commands.execute()` 或 `actions.run_command()` 即可。
